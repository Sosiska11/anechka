# PLAN.md — Локальный органайзер расписания и тем уроков для учителя биологии

## 1. Концепция и цель проекта
**Название:** Планер биолога (BioPlanner)  
**Формат:** Mobile-first веб-приложение (SPA), предназначенное для последующей упаковки в автономный Android `.apk` через **Capacitor**.  
**Целевая аудитория:** Школьный учитель **биологии**.  
**Ключевое требование:** 100% локальная работа (Offline-first). Без серверов, регистрации и интернета. Все данные хранятся локально в памяти устройства (`localStorage` с версионированием и функцией экспорта/импорта JSON-резервной копии).  
**Визуальный стиль:** Спокойная природная палитра — изумрудно-зелёные акценты (`emerald-600` / `#059669`), светлый фон (`slate-50`), крупные карточки и удобное управление одной рукой.  
**Упрощённая структура:** Учитель ведёт школьную биологию для классов 5–11 (литеры параллелей А–Е). Выбор класса реализован в 1–2 клика через удобный селектор (параллели 5–11 и литеры А–Е). Блок оборудования и деление на подтемы исключены для максимальной простоты и скорости заполнения тем.

## 2. Технологический стек
* **Фреймворк:** React 18+ + TypeScript + Vite
* **Стилизация:** Tailwind CSS (мобильная адаптация, контейнер `max-w-md mx-auto` для удобной отладки на ПК и нативного вида на телефоне)
* **Иконки:** `lucide-react` (`Microscope`, `FlaskConical`, `FileSpreadsheet`, `Leaf`, `BookOpen` и др.)
* **Работа с датами:** `date-fns` (с русской локалью `date-fns/locale/ru`)
* **Хранилище:** `localStorage` через изолированный сервис `storageService.ts`
* **Нативная обёртка (Финальный этап):** `@capacitor/core`, `@capacitor/android`, `@capacitor/local-notifications`

## 3. Архитектура данных (TypeScript-модели)

```typescript
// Слот расписания звонков (1–8 уроки)
export interface BellSlot {
  lessonNumber: number; // 1, 2, 3...
  startTime: string;    // "08:30"
  endTime: string;      // "09:15"
}

// Постоянный шаблон недели (повторяется каждую неделю)
export interface ScheduleTemplateItem {
  id: string;
  dayOfWeek: 1 | 2 | 3 | 4 | 5 | 6; // 1 = Пн, ..., 6 = Сб
  lessonNumber: number;
  className?: string;   // Например: "7А", "10Б", "11Г"
  roomOverride?: string; // Если урок проходит не в основном кабинете биологии
}

// Тип урока биологии
export type LessonType = 'regular' | 'lab' | 'practical' | 'test';

// Конкретный урок на конкретную календарную дату
export interface LessonInstance {
  id: string;
  date: string;         // Формат "YYYY-MM-DD"
  lessonNumber: number;
  className?: string;   // Например: "7А", "11В"
  room: string;         // Подставляется из AppSettings.defaultRoom, если не переопределён
  topic: string;        // Тема урока
  lessonType: LessonType; // Обычный / Лабораторная / Практическая / Контрольная
  homework: string;     // Домашнее задание
  notes: string;        // Личные заметки ("проверить тетради", "распечатать карточки")
  status: 'planned' | 'completed' | 'cancelled';
  isExtra?: boolean;    // true, если это разовый урок / замена вне шаблона
}

// Особые дни (каникулы, праздники, отмены)
export interface DayOverride {
  date: string;         // "YYYY-MM-DD"
  isHoliday: boolean;
  label?: string;       // Например: "Осенние каникулы"
}

// Настройки приложения
export interface AppSettings {
  defaultRoom: string;                  // Основной кабинет биологии (например, "304")
  reminderMinutesBefore: number | null; // 5, 10, 15 или null (выкл)
  eveningReminderTime: string | null;   // Например: "19:00" или null
  showSaturday: boolean;                // Показывать ли субботу в сетке
}

// Вспомогательный интерфейс для отображения урока в интерфейсе (объединённые данные)
export interface DisplayLesson {
  id: string;                  // ID инстанса или виртуальный ID
  date: string;                // "YYYY-MM-DD"
  lessonNumber: number;
  className?: string;          // Например: "7А", "9Б"
  startTime: string;           // "08:30"
  endTime: string;             // "09:15"
  room: string;                // "304"
  topic: string;               // Тема урока
  lessonType: LessonType;      // Тип урока
  homework: string;            // Домашнее задание
  notes: string;               // Заметки
  status: 'planned' | 'completed' | 'cancelled';
  isExtra?: boolean;
  isVirtual: boolean;          // true, если урок сгенерирован по шаблону и еще не сохранен как экземпляр
}
```

## 4. Ключевая бизнес-логика

1. **Генерация уроков на выбранную дату (`getLessonsForDate(date)`):**
   * Если дата помечена в `DayOverride` как `isHoliday: true`, возвращается пустой список и плашка выходного дня.
   * Система проверяет, есть ли в хранилище сохранённые `LessonInstance` на эту дату.
   * Если сохранённых записей на эту дату ещё нет, приложение автоматически формирует виртуальный список уроков на основе `ScheduleTemplateItem` для соответствующего дня недели (`dayOfWeek`), подставляя `roomOverride` или `AppSettings.defaultRoom`.
   * Как только учитель открывает урок и вписывает тему, ДЗ или меняет статус/тип урока, запись сохраняется в массив `LessonInstance` для этой конкретной даты, не затрагивая другие недели.

2. **Функция «Перенести тему на следующий урок»:**
   * В карточке урока есть кнопка **«Не успели: перенести тему на следующий урок»**.
   * При нажатии система находит ближайший следующий урок по расписанию (сначала проверяет существующие будущие `LessonInstance`, если их нет — вычисляет ближайшую дату по `ScheduleTemplateItem` с учётом выходных/каникул).
   * В найденный следующий урок переносятся **Тема урока**, **Тип урока** (например, запланированная лабораторная) и **Домашнее задание**, а текущий урок получает пометку в заметках «Тема перенесена».

## 5. Структура экранов и навигация

Приложение имеет фиксированную нижнюю панель навигации (4 вкладки) и шапку с названием текущего раздела.

### Вкладка 1: «Сегодня» (Главный экран)
* **Верхняя панель:** Название месяца/года + горизонтальная лента дней текущей недели (Пн–Сб) с быстрым переключением и кнопкой возврата на «Сегодня».
* **Виджет ближайшего урока:** Подсвеченная изумрудная карточка текущего или следующего урока по времени звонков (показывает бейдж класса, например «7А», кабинет, тему и сколько минут осталось до начала).
* **Список уроков дня:** Карточки уроков по порядку:
  * Номер урока, время звонка, кабинет.
  * Бейдж и заголовок класса (например, `7А класс` или `Класс ?`, если не указан).
  * Бейдж типа урока, если это не обычный урок (например, `Лабораторная работа` с иконкой микроскопа, `Практическая`, `Контрольная`).
  * Тема урока (или подсказка «Нажмите, чтобы записать тему»).
  * Превью ДЗ и наличие заметок.
* **Кнопка `+ Добавить урок`:** Позволяет вручную добавить урок в любой свободный слот на выбранную дату (выбирается класс 5–11 А–Е, номер урока и кабинет).
* **Шторка/модальное окно редактирования урока (открывается по клику на карточку):**
  * Выбор **Класса** (параллели 5–11 и литеры А–Е в 1 клик).
  * Выбор **Типа урока** (`Обычный`, `Лабораторная`, `Практическая`, `Контрольная`).
  * Поле **Тема урока**.
  * Поле **Домашнее задание**.
  * Поле **Заметки для себя**.
  * Поле **Кабинет** (по умолчанию подставлен основной кабинет из настроек, можно изменить).
  * Переключатель статуса: `Запланирован` / `Проведён` / `Отменён`.
  * Кнопка **«Перенести тему на следующий урок»** (копирует тему и ДЗ в следующий урок этого же класса по расписанию).

### Вкладка 2: «Календарь» (Обзор по числам и неделям)
* **Переключатель вида:** `Месяц` / `Неделя`.
* **Режим «Месяц»:** Полноценная сетка месяца с переключением `< Месяц Год >` и кнопкой быстрого возврата на «Сегодня». Под каждым числом — индикаторы-точки:
  * Зелёная точка — на этот день есть уроки и темы заполнены.
  * Серая / янтарная точка — уроки по расписанию есть, но темы ещё пустые.
  * Без точек — выходной день или уроков нет.
  * Иконка микроскопа / колбы, если запланирована лабораторная или практическая работа.
  * Розовый фон — каникулы / праздничный выходной.
* **Режим «Неделя»:** Компактный список дней недели Пн–Сб со списком классов (например `7А`, `8Б`, `10А`), статусом тем и быстрыми кнопками перехода к урокам дня.
* **Действия:** Клик по любому числу открывает детальный список уроков этого дня или переводит на главный экран «Сегодня» с выбранной датой для заполнения тем и ДЗ на будущие недели.

### Вкладка 3: «Расписание» (Сетка звонков и шаблон недели)
Внутри 2 удобных подвкладки:
1. **Шаблон недели:** Выбор дня недели (Пн, Вт, Ср, Чт, Пт, Сб). Для каждого дня учитель может настроить постоянные уроки: выбрать класс (5–11, А–Е), номер урока (время подтягивается из звонков) и кабинет (по умолчанию из Настроек). В карточке слота шаблона выводится бейдж класса.
2. **Звонки:** Редактирование времени начала и окончания каждого урока (1–8 уроки) с расчётом длительности и перемен.

### Вкладка 4: «Настройки»
* **Мой кабинет по умолчанию:** Поле ввода номера кабинета (например, `304`), который автоматически подставляется во все уроки.
* **Учебная неделя:** Переключатель «Показывать субботу» (6-дневная учебная неделя).
* **Блок «Напоминания» (Локальные уведомления без интернета):**
  * Переключатель «Напоминать перед уроком» с выбором времени (за 5, 10 или 15 минут). Текст: «Скоро урок (время) • Каб. [номер]» и тема урока.
  * Переключатель «Вечернее напоминание в 19:00» («Проверьте темы уроков на завтра»).
  * Автоматический планировщик `@capacitor/local-notifications` на 7 дней вперёд.
* **Блок «Резервные копии»:**
  * Кнопка **«Сохранить копию»** (скачивание `biology-backup-YYYY-MM-DD.json`).
  * Кнопка **«Скопировать код копии»** (в буфер обмена для Telegram / заметок).
  * Кнопка **«Восстановить из файла»** (выбор файла .json или вставка текста копии).
* **Сброс и демо-расписание:** Кнопка «Сбросить и загрузить расписание биологии».
* В самом низу полупрозрачная подпись: `© Сделано с любовью <3`.
